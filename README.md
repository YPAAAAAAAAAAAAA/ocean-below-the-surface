# ocean-below-the-surface

A clean-room, from-scratch re-implementation of the idea behind **[snychng/ocean-below-the-surface](https://github.com/snychng/ocean-below-the-surface)** by [@snychng](https://github.com/snychng). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
